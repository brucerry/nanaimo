# Play Nanaimo

1. On Windows 10 or 11 x64, open **Start-Game.exe**.
2. Enter an account in **Local login**, then click **Log in and play**.
3. Create a character if this is a new account; otherwise your character resumes.
4. Exit the game and click **Stop server** when finished.

Keep this entire folder together when moving the game. No developer tools are
needed. The launcher and server runtimes are included in `server/`.

Back up `server/server-merged/data/` with the game and server stopped.
**Reset saves** archives all accounts and progress; it is not part of normal startup.

See [runtime details](server/README.md) or the [workspace guide](../README.md).
